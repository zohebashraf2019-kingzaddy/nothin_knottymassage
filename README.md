# Nothin' Knotty Massage LLC — Website

Static site for Nothin' Knotty Massage LLC (Juliet Fulton, Reno NV). Built by Nexora Digital.

**Pages:** `index.html` (services, add-ons, specials/giveaway, aromatherapy guide, hours & map, Instagram, FAQ) · `about.html` · `booking.html` (planner + calendar → GlossGenius) · `contact.html`

**Edit in one place:** `js/main.js` → `CONFIG` (booking URL, phone, Instagram, form endpoint), `HOURS`, `SERVICES`, `ADDONS`.

**Contact form:** set `CONFIG.formEndpoint` to a Formspree/Web3Forms endpoint to receive messages by email. Left blank, it opens a pre-filled text to (775) 433-8937.

**Deploy:** import the repo in Vercel — no build step (framework preset: Other).
